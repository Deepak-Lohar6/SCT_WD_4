# ❖ TaskFlow — Interactive Task Management Web Application

TaskFlow is a responsive, client-side web application built for organizing, tracking, and prioritizing daily tasks. It features real-time search filtering, dynamic category tagging, interactive metrics analytics, progress tracking, theme switching, and persistent state management using LocalStorage.

## 🚀 Overview

TaskFlow simplifies daily workflow planning through a fast, distraction-free dashboard interface. Designed as a single-page application (SPA), it provides instant feedback for task creation, editing, completion tracking, and category filtering while automatically persisting data locally across session reloads.

This project fulfills **Task 04: To-Do Web Application** for the **SkillCraft Technology Web Development Internship**.

---

## ✨ Key Features

* **Task Management:** Create, edit, complete, undo, and delete daily tasks.
* **Category Tagging:** Organize tasks into dedicated categories (Business, Knowledge, Personal, Vitality, and Special).
* **Real-time Analytics Dashboard:** Dynamic tracking of total tasks, completed tasks, and pending items.
* **Progress Meter:** Live visual progress bar calculating completion rates dynamically.
* **Instant Search Filtering:** Search and filter tasks by title or category in real time.
* **Light / Dark Mode Toggle:** Seamless theme switcher with persistent local storage saving.
* **LocalStorage Persistence:** All task states and preferences remain saved upon browser refresh.
* **Responsive Layout:** Optimized across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom CSS variables, Flexbox, Grid layouts, theme transitions, and responsive media queries.
* **JavaScript (ES6+):** DOM manipulation, event listeners, state management, LocalStorage API, and search algorithms.
